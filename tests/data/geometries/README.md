# Test geometries (frozen)

Copies of the example geometries as they were when the committed meshes (`../meshes`) and the regression
references (`../../reference`) were made, with the original group names (`submeca_membranne`,
`interface_constrained_rz_1`, …). The tests use these, never the examples' geometries, so renaming or editing
an example cannot change a test input. The examples' copies (`examples/Geometries`) use readable names.
